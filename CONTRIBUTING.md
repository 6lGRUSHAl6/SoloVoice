# 📖 Инструкция для разработчиков

## 🎯 Структура проекта

- **main.py** — точка входа приложения
- **config.py** — управление конфигурацией и окружением
- **cogs/** — модули функциональности (Cogs)
- **utils/** — вспомогательные функции и классы

## 🔄 Рабочий процесс

### 1. Подготовка окружения

```bash
# Создание виртуального окружения
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows

# Установка зависимостей
pip install -r requirements.txt
```

### 2. Разработка

- Добавляйте новые команды в `cogs/voice_commands.py` или создавайте новые Cogs
- Разделяйте логику по модулям в `utils/`
- Следуйте стилю кода, используемому в проекте

### 3. Тестирование локально

```bash
# Создайте .env файл с токеном
python main.py
```

### 4. Запуск через Docker

```bash
docker-compose up
```

## 📋 Кодирование

- Используйте Type Hints для функций
- Добавляйте docstring'и на русском языке
- Комментируйте сложную логику
- Следуйте PEP 8

## 🚀 Развертывание

- Обновите версию в комментариях
- Все образы собираются в Docker
- Используйте `docker-compose up -d` для продакшена

## 🐛 Отладка

Логи можно смотреть через:
```bash
docker-compose logs -f discord-bot
```

Или в консоли при локальном запуске.
